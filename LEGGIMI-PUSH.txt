============================================================
PROCEDURA DI INSTALLAZIONE
============================================================

1) Estrai tutto lo ZIP DENTRO la cartella root del tuo progetto
   (la cartella che contiene package.json, src/, public/, prisma/)

2) Apri PowerShell nella cartella del progetto

3) Verifica che i file siano stati copiati:
   git status

4) Aggiungi tutti i file:
   git add .

5) Commit:
   git commit -m "feat: Web Push Notifications (VAPID) - backend + frontend"

6) Push su GitHub:
   git push origin main

7) Vai su Vercel e aspetta che il deploy finisca (2-3 minuti)
   https://vercel.com/riccardofreddis-projects/portale-pfc-v2/deployments
